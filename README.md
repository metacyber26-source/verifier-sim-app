# Verifier Sim App

Aplikasi simulasi interaktif berbasis web untuk melatih keterampilan Verifikator / Validator lintas bidang secara bertahap (Beginner hingga Expert).

## Cara Deploy ke Vercel

1. Push seluruh kode ini ke repository GitHub Anda dengan nama `verifier-sim-app`.
2. Buka [Vercel](https://vercel.com) dan login dengan akun GitHub Anda.
3. Klik **"Add New Project"** -> Pilih repository `verifier-sim-app`.
4. Klik **"Deploy"** (Tanpa perlu konfigurasi Build Command karena menggunakan pure Standalone Web Tech).
5. Aplikasi siap diakses melalui HP Samsung Galaxy A16 atau browser desktop!
